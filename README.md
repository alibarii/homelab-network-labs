## 📌 Featured Projects

### 1. 🖥️ Raspberry Pi 4 Automated Web Kiosk Display
- **Objective:** Configure a single-board computer (Raspberry Pi 4 Model B) to boot directly into an automated Chromium web kiosk for continuous dashboard display.
- **Tech Stack & Hardware:** Raspberry Pi 4 Model B, Raspberry Pi Imager, Chromium, SSH, Raspberry Pi Connect.
- **Key Highlights & Troubleshooting:**
  - **EEPROM Recovery:** Diagnosed cold boot / HDMI display failure and restored hardware functionality by re-flashing EEPROM firmware using Raspberry Pi Imager.
  - **Kiosk Automation:** Configured automated Chromium launch with custom flags (`--kiosk`, `--noerrdialogs`) for uninterrupted visual monitoring.
